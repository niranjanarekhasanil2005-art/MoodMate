# 🌸 MoodMate — Your Feelings, Your Space

Welcome to **MoodMate**, your gentle, private mood companion web app!

---

## 🚀 How to Run in Google Chrome (Quick & Easy)

Since MoodMate is built with pure HTML, CSS, and JavaScript, **you don't need to install anything!**

### Method 1: Double-Click
1. Open this folder in Windows File Explorer:
   `Documents\MoodMate`
2. Look for the file named **`index.html`**.
3. **Double-click** it! It will immediately open in your default browser (Google Chrome).

### Method 2: Open with Chrome Directly
1. Right-click on **`index.html`**.
2. Select **Open with** > **Google Chrome**.

### Method 3: Drag and Drop
1. Open Google Chrome.
2. Drag the **`index.html`** file from your folder and drop it into any Chrome tab.

## ✨ Features Included

- **Pastel Lavender & Pink Aesthetic:** Soft calming gradients, ambient glowing background orbs, and glassmorphism styling.
- **Mood Recognition Rules (Pure JavaScript):**
  - 😄 **Happy**
  - 🥺 **Sad**
  - 😤 **Angry**
  - 😰 **Anxious**
  - 🤩 **Excited**
  - 🥱 **Tired**
  - 🌸 **Thoughtful & Calm** (friendly fallback for neutral thoughts)
- **Graceful Empty State:** Friendly reminder when clicking the button without typing anything.
- **Supportive Messages:** Warm, personalized self-care notes for every feeling.
- **Quick Test Chips:** One-click buttons to instantly test sample moods.
- **Keyboard Shortcut:** Press **Enter** in the text box to predict your mood immediately.
- **100% Private:** Runs entirely inside your browser. No backend, no APIs, and zero data leaves your computer.
